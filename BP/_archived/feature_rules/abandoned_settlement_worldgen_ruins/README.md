# Archived: global abandoned settlement ruin scatter

These `feature_rules` placed tiny **barrel / cobweb / mossy cobblestone** patches during chunk worldgen in plains, desert, savanna, taiga, snowy, ice, meadow, and force-test biomes.

**Removed from active pack** (2026-06) — full abandoned villages are **script-only** (`mb_abandonedVillageWorldgen.js` + `mb_abandonedSettlementBuilder.js`). **Lamp post markers** remain under `BP/feature_rules/village_marker_*.json`.

Already-generated chunks may still have old ruins until you explore new areas or create a new world.

Restore only if you want both worldgen micro-ruins and script hamlets (not recommended).
