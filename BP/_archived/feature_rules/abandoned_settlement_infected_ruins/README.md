# Archived: infected biome worldgen ruin scatter

These `feature_rules` placed tiny **barrel/cobweb ruin** patches during chunk worldgen in infected biomes.

**Removed from active pack** (2026-05) — full abandoned villages are **script-only** (`mb_abandonedVillageSites.js` + builder). No barrel/cobweb scatter in infected biomes from worldgen.

Already-generated chunks may still have old ruins until you explore new areas or edit the world.

Restore only if you want both worldgen micro-ruins and script hamlets (not recommended).
