# Dev Beta 4.1 — The Maple Bear Apocalypse (Dev pack only)

**Label:** `v0.9.0-beta.4.1 (dev build)`  
**Base public release:** `v0.9.0-beta.4`  
**Audience:** Patreon / internal playtest — **`BP - Dev/` + `RP - Dev/`** (not GitHub Release zips).

## Install

1. Remove old dev packs from the world.
2. Import **`The Maple Bear Apocalypse (Dev)`** behavior + resource from Bridge `.mcpack` export (or sync repo folders).
3. **New chunks** required for lamp markers and village grid sites.

## Highlights

See Patreon post / `docs/context summary.md` (2026-06 sections) for full detail.

- Procedural **abandoned villages** (hamlet / village / large) via script — vanilla villages disabled.
- **Lamp post markers** on worldgen grid; walk up to trigger phased builds.
- **8 biome rulesets**, 70+ house shells, churches, work buildings, infected large slots.
- Village **chest loot** via vanilla tables + fallbacks.
- **Perf:** phased build, adaptive budgets, chunk-edge defer, day-0 throttle (carried from post–beta.4 dev work).
- Dev journal: **Abandoned villages** debug, export starter set, force-place menus.
